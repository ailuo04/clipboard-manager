# 5,000 条历史性能基线

生成时间：2026-11-11（本机，合成数据）。这是可重复的开发基线，不是通用性能承诺或验收阈值。

## 运行方法

在 Windows PowerShell 7、仓库根目录运行：

```powershell
pwsh -NoProfile -File tests/performance/Measure-History.ps1
```

脚本创建 5,000 条全新的合成 SQLite 历史记录（2,500 条文本、2,500 条图片元数据），测量首次文本查询、重复查询、短查询、全量结果页、写入时间、数据库大小，以及重复搜索前后的托管堆和进程工作集差值。测试数据库与中间报告只写入系统临时目录；最终 JSON 不记录机器名、用户路径、剪贴板内容或用户历史。

原始结果见 [`history-5000-baseline.json`](history-5000-baseline.json)。本次环境：Dell G15 5525、Windows 11 x64 build 26300、AMD Ryzen 7 6800H（16 个逻辑处理器）、约 15 GiB 内存、NVMe SSD、.NET SDK 10.0.403 / runtime 10.0.14、Microsoft.Data.Sqlite 10.0.14、SQLite 3.53.3。

## 本次结果

- 数据库：5,000 条记录，约 2.41 MB；合成数据填充约 318 ms。
- 首次匹配查询（50 条命中）：约 28.6 ms。
- 同一查询随后 20 次：中位数约 20.5 ms，P95 约 32.9 ms，最大约 33.0 ms。
- 1 字符短查询：约 13.9 ms，2,500 条命中。
- 首次全量页查询：约 30.6 ms。
- 20 次重复搜索后的托管堆差值约 39 KiB；进程工作集差值约 -456 KiB（样本结束时降低）。这是运行前后差值，不是峰值内存或专用 profiler 结果。

计时受系统负载、文件缓存、SQLite/JIT 暖机影响；单次数据仅作为当前基线，不能据此宣称所有机器的表现相同。后续基线应在相近环境使用相同脚本重新生成并保留新旧环境说明，不先编造性能预算。

## 未测项目

这次没有启动 WinUI App，因此没有测量滚动帧卡顿、UI Dispatcher 延迟、真实缩略图解码并发或窗口缩放布局。数据库图片记录只含合成元数据/路径，没有实际 PNG 字节。上述项目以及 720/900/1440 宽度、高 DPI、键盘/读屏、WPF→WinUI 安装迁移仍需在一次性 Windows 用户环境完成验收；当前性能文件不代表这些项目已通过。
