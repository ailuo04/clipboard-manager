# 剪贴板使用说明

## 启动

适用于 Windows 11 x64，提供两种方式：

- 安装版：运行 `ClipboardManager-0.0.7-win-x64-setup.exe`，按中文向导安装。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ClipboardManager`；“创建桌面快捷方式”和安装完成页的“启动剪贴板”默认勾选，可手动取消，重装时也使用这两个默认值。保持勾选并点击“完成”后启动程序，也可从开始菜单打开“剪贴板”。
- 便携版：将发行版 ZIP 完整解压到普通文件夹，双击 `ClipboardManager.exe`。不要直接在压缩包内启动，也不要只移动 EXE。

两种版本均自带 .NET 运行环境，无需另外安装 SDK 或运行时，不需要管理员权限。仓库已公开，正式发行版可直接下载。它们共用同一个历史数据目录，不能同时运行。安装或升级前先退出已运行的剪贴板程序。

程序尚未进行代码签名。Windows 可能提示无法识别发布者；请先确认下载来自你信任的 GitHub 仓库，并核对同一发行版的 SHA256 文件。不要为了运行它而关闭系统安全防护。

## 主要功能

| 功能 | 操作与作用 |
| --- | --- |
| 文本与图片历史 | 启动后自动记录新复制的文本、截图和支持的图片，重启后保留历史 |
| 快速复制 | 点击记录主体或复制按钮，再到目标软件按 Ctrl+V；不会自动向其他软件粘贴 |
| 复制后自动隐藏 | 默认开启：复制记录后窗口自动隐藏并把焦点还给之前的窗口，可直接粘贴；可在设置中关闭 |
| 搜索与筛选 | 搜索完整文本，切换全部、文本、图片；输入搜索词时不显示图片，筛选栏会提示 |
| 固定记录 | 固定重要内容，避免因容量限制而自动清理；固定不等于窗口置顶 |
| 内容详情 | 查看完整文本；图片支持适应窗口和缩放 |
| 全局唤起 | Ctrl+Shift+Space 显示、恢复或激活窗口，不替代系统 Win+V |
| 键盘选择 | 方向键选择，Enter 或 Ctrl+C 复制，Delete 删除，Ctrl+P 固定 |
| 数字快选 | 列表有焦点时按 1–9 直接复制对应序号的记录（序号显示在卡片左上角） |
| 快速退出 | Esc 清空搜索词（搜索框有内容时）或隐藏窗口；覆盖层打开时 Esc 返回上一页 |
| 窗口置顶 | 标题栏图钉或设置中切换，重启后保留 |
| 暂停监听 | 暂停后不记录新复制内容，恢复时不会补记暂停期间的内容 |
| 容量管理 | 默认最多 500 条、512 MB，设置中可调整；优先清理最早的未固定内容 |
| 删除与清空 | 删除单条；清空需要确认，且包含固定记录 |
| 外观主题 | 设置中可切换深色、浅色或跟随 Windows 应用主题；点选即时预览，保存后记住选择；跟随系统时随系统设置自动切换 |

最小化后继续监听；在设置中启用“关闭窗口时最小化到系统托盘”后，关闭窗口会保留后台监听，可从托盘菜单重新打开、暂停或恢复监听、退出。该选项默认关闭；程序没有开机自启。复制相同内容会更新原记录时间，不会重复占用历史位置。

## 应用内更新

主界面和设置页均有更新图标。默认启动后自动检查，运行期间每 6 小时检查一次；“自动检查更新”可在设置中关闭。发现新版后，打开更新窗口查看下载量，点击“更新并重启”，确认后下载并重启。

只下载有变动或新增的文件，不下载整份安装包或 ZIP；未变化的运行环境不动。改动文件按完整文件压缩传输，不是字节级差分。新版不再需要的旧发行文件会删除，但历史、图片、设置、用户添加的文件不会被删除。只暂存本次变动，成功启动后清理备份和下载临时文件。下载可取消，失败保留旧版；替换中断后再次启动会尝试自动恢复。

更新器匿名读取公开仓库 `ailuo04/clipboard-manager` 的最新正式版，无需登录或配置令牌。版本清单和逐文件压缩附件与安装包放在同一条正式 Release 中；`v0.0.3` 及更早版本可能仍使用同仓库的 `updates-v版本号` 预发布数据区，客户端保留兼容读取。

旧版没有更新器，需先手动升级一次。新版发布端必须提供完整的文件清单和增量附件，程序目录需要可写；不满足时报告原因，不会改为全量下载。

更新器只检查最新正式版，不会把预发布版误判为最新版。正式 Release 同时包含应用安装包和内部差量更新附件；普通用户无需手动下载更新附件。附件虽然包含发行文件的压缩内容，应用实际只下载本机缺少或哈希不同的文件，删除新版清单中已移除的旧发行文件，并保留未变化文件、剪贴板历史和设置。

## 隐私与数据

所有记录只保存在本机，应用不上传剪贴板内容、不提供云同步。文本与图片没有额外加密，密码、验证码、密钥等也可能被记录，复制敏感信息前请暂停监听。

数据目录：`%LOCALAPPDATA%\ClipboardManager`。其中 `history.json` 保存文本、索引与设置，`theme.json` 保存主题偏好，`images` 保存历史图片，`app.log` 保存诊断信息。设置中可以打开数据目录和日志。

安装版升级：先退出应用，再运行新版本安装包，可覆盖升级，无需先卸载。卸载可在 Windows“设置 → 应用 → 已安装的应用”中找到“剪贴板”，或运行安装目录的 `unins000.exe`；卸载会移除程序与快捷方式，但保留上述历史数据目录。

便携版升级：先退出应用，再将新版本解压到新文件夹运行；卸载只需在退出后删除程序文件夹。不要删除数据目录，除非你确实想清除全部历史。彻底删除历史需要另行删除 `%LOCALAPPDATA%\ClipboardManager`，删除数据不可恢复。

## 已知限制

- 仅记录启动且未暂停期间发生的新复制操作。
- 不做图片 OCR；文本搜索不能搜索图片中的文字。
- 多张图片文件同时复制时只记录第一张支持的图片，GIF/TIFF 只保留首帧。
- 全局快捷键被其他应用占用时会显示提示，其他功能仍可使用。
- 单次读取最大 128 MB，Unicode 文本最大 8 MB，解码图片最大 4000 万像素；高频连续复制可能合并。
- 固定记录不会自动清理，因此固定内容本身可以超过容量上限。
- 随包运行环境由发行版维护。发布包含安全修复的新版后，更新器也只下载其中发生变化的运行环境文件。
