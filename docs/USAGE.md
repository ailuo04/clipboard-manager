# 剪贴板使用说明

## 启动

适用于 Windows 11 x64，提供两种方式：

- 安装版：运行 `ClipboardManager-0.0.16-win-x64-setup.exe`，按中文向导安装。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ClipboardManager`；“创建桌面快捷方式”和安装完成页的“启动剪贴板”默认勾选，可手动取消，重装时也使用这两个默认值。保持勾选并点击“完成”后启动程序，也可从开始菜单打开“剪贴板”。
- 便携版：将发行版 ZIP 完整解压到普通文件夹，双击 `ClipboardManager.exe`。不要直接在压缩包内启动，也不要只移动 EXE。

两种版本均自带 .NET 运行环境，无需另外安装 SDK 或运行时，不需要管理员权限。仓库已公开，正式发行版可直接下载。它们共用同一个历史数据目录，不能同时运行。安装或升级前先退出已运行的剪贴板程序。

程序尚未进行代码签名。Windows 可能提示无法识别发布者；请先确认下载来自你信任的 GitHub 仓库，并核对同一发行版的 SHA256 文件。不要为了运行它而关闭系统安全防护。

## 主要功能

程序由始终置顶的胶囊和按需打开的历史记录弹窗组成。

- **胶囊**（240×40）：显示监听状态、最新内容和记录条数。点击内容复制最新记录，点击右侧箭头查看历史；拖动左侧状态圆点区域移动，位置会记住。
- **历史弹窗**：在胶囊旁显示最近复制的记录。点击记录复制，悬停预览文字或图片，按住记录可拖入其他兼容应用。长文本预览会截断，复制始终获取完整内容。
- **菜单**：右键胶囊或点击历史弹窗底部的“更多”，可暂停/恢复监听、打开设置、检查更新、清空历史和退出。

| 功能 | 操作与作用 |
| --- | --- |
| 文本与图片历史 | 启动后自动记录新复制的文本、截图和支持的图片，重启后保留历史 |
| 快速复制 | 点击记录，再到目标软件按 Ctrl+V；不会自动向其他软件粘贴 |
| 弹窗关闭 | 复制完成、按 Esc 或点击外部后关闭历史弹窗；胶囊继续显示，拖拽过程中延迟关闭 |
| 隐藏最新内容 | 设置中勾选“胶囊上不显示最新内容”后，胶囊只显示“剪贴板”和记录条数 |
| 设置与更新 | 以卡片显示，窗口临时提供卡片所需空间；关闭后恢复胶囊，从历史弹窗打开时返回历史弹窗 |
| 全局唤起 | Ctrl+Shift+Space 打开历史弹窗并聚焦列表，弹窗已在前台时再按一次关闭；不替代系统 Win+V |
| 键盘选择 | 列表获得焦点后，方向键选择，Enter 或 Ctrl+C 复制 |
| 页面返回 | 设置等页面打开时，Esc 或卡片右上角关闭按钮返回；从设置进入更新时先返回设置 |
| 暂停监听 | 暂停后不记录新复制内容，恢复时不会补记暂停期间的内容 |
| 容量管理 | 默认最多 500 条、512 MB，设置中可调整；已有固定记录继续按原规则保留 |
| 清空历史 | 需要确认，包含已有固定记录及对应图片 |
| 外观主题 | 设置中可切换深色、浅色或跟随 Windows 应用主题，点选即时预览，保存后记住选择 |

关闭历史弹窗后继续监听。退出程序用胶囊右键菜单或“更多”菜单里的“退出”。设置中启用“关闭窗口时最小化到托盘”后，关闭主窗口会隐藏胶囊并继续后台监听；卡片右上角的关闭按钮只关闭当前页面。托盘菜单可打开历史弹窗、暂停/恢复监听或退出。程序没有开机自启。再次启动程序会唤起已运行实例的历史弹窗；设置等卡片打开时保留当前页面。复制相同内容会更新原记录时间，不会重复占用历史位置。

## 图片编辑

- 在历史记录中右键图片，选择“编辑图片”。也可右键胶囊，选择“编辑最新图片”：仅当最新一条记录是图片时可用；最新内容是文本或历史为空时禁用，不会跳过文本去编辑较早的图片。
- 选择“文字”，点击图片上的位置直接输入，输入框和光标会标明当前位置。Enter 换行，Esc 完成输入；双击已有文字可继续修改，拖动输入框边框可移动位置。
- 顶部字体区域可选择本机已安装的常用字体，如宋体、微软雅黑、Times New Roman、Arial；可调整字号（6–512 像素，按原图计算）和文字颜色。
- 选择“箭头”或“矩形”，在图片上按住鼠标拖动绘制，可设置自定义颜色和线条粗细。选中箭头后拖动端点可改变长度和方向；选中矩形后拖动四角可改变大小，拖动边框可移动。
- 使用“选择”工具选中、移动或删除标注。顶部工具和属性区域随当前工具或所选标注切换，支持深色与浅色主题。
- 点击“保存并复制”，按原图像素尺寸生成新图片记录并复制到剪贴板，保留原图片；输入框、光标及控制点不会写入图片。保存或复制失败时保留当前标注，可重试。

## 应用内更新## 应用内更新

胶囊右键菜单、历史弹窗“更多”菜单和设置页均可检查更新。默认启动后自动检查，运行期间每 6 小时检查一次；“自动检查更新”可在设置中关闭。发现新版后，打开更新窗口查看下载量，点击“更新并重启”，确认后下载并重启。

只下载有变动或新增的文件，不下载整份安装包或 ZIP；未变化的运行环境不动。改动文件按完整文件压缩传输，不是字节级差分。新版不再需要的旧发行文件会删除，但历史、图片、设置、用户添加的文件不会被删除。只暂存本次变动，成功启动后清理备份和下载临时文件。下载可取消，失败保留旧版；替换中断后再次启动会尝试自动恢复。

更新器匿名读取公开仓库 `ailuo04/clipboard-manager` 的最新正式版，无需登录或配置令牌。版本清单和逐文件压缩附件与安装包放在同一条正式 Release 中；`v0.0.3` 及更早版本可能仍使用同仓库的 `updates-v版本号` 预发布数据区，客户端保留兼容读取。

旧版没有更新器，需先手动升级一次。新版发布端必须提供完整的文件清单和增量附件，程序目录需要可写；不满足时报告原因，不会改为全量下载。

更新器只检查最新正式版，不会把预发布版误判为最新版。正式 Release 同时包含应用安装包和内部差量更新附件；普通用户无需手动下载更新附件。附件虽然包含发行文件的压缩内容，应用实际只下载本机缺少或哈希不同的文件，删除新版清单中已移除的旧发行文件，并保留未变化文件、剪贴板历史和设置。

## 隐私与数据

所有记录只保存在本机，应用不上传剪贴板内容、不提供云同步。文本与图片没有额外加密，密码、验证码、密钥等也可能被记录，复制敏感信息前请暂停监听。

数据目录：`%LOCALAPPDATA%\ClipboardManager`。其中 `history.json` 保存文本、索引与设置，`theme.json` 保存主题偏好，`images` 保存历史图片，`app.log` 保存诊断信息。设置中可以打开数据目录和日志。

安装版升级：先退出应用，再运行新版本安装包，可覆盖升级，无需先卸载。卸载可在 Windows“设置 → 应用 → 已安装的应用”中找到“剪贴板”，或运行安装目录的 `unins000.exe`；卸载会移除程序与快捷方式，但保留上述历史数据目录。

便携版升级：先退出应用，再将新版本解压到新文件夹运行；卸载只需在退出后删除程序文件夹。不要删除数据目录，除非你确实想清除全部历史。彻底删除历史需要另行删除 `%LOCALAPPDATA%\ClipboardManager`，删除数据不可恢复。

## 已知限制

- 仅记录启动且未暂停期间发生的新复制操作。
- 不做图片 OCR。
- 多张图片文件同时复制时只记录第一张支持的图片，GIF/TIFF 只保留首帧。
- 全局快捷键被其他应用占用时会显示提示，其他功能仍可使用。
- 单次读取最大 128 MB，Unicode 文本最大 8 MB，解码图片最大 4000 万像素；高频连续复制可能合并。
- 旧数据中已有的固定记录不会自动清理，因此其内容本身可以超过容量上限。
- 随包运行环境由发行版维护。发布包含安全修复的新版后，更新器也只下载其中发生变化的运行环境文件。
