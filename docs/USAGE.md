# 剪贴板管理器使用说明

适用于 Windows 11 x64。应用以 WinUI 3 单窗口提供历史、收藏、更新中心和设置；剪贴板数据只在本机处理。

## 安装和首次启动

### 安装版

下载同一 Release 中的 `ClipboardManager-<版本>-win-x64-setup.exe` 与 `.sha256` 文件，先核对 SHA-256，再运行安装器。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ClipboardManager`，不要求管理员权限。

### 便携版

下载 `ClipboardManager-<版本>-win-x64.zip` 与 `.sha256` 文件并核对哈希。将 ZIP **完整解压**到普通目录，启动 `ClipboardManager.App.exe`；不要只复制 EXE，也不要从压缩包内启动。

安装版和便携版共用 `%LOCALAPPDATA%\ClipboardManager` 数据，不能同时运行。安装器卸载程序文件与快捷方式时会保留该数据目录。

### 从旧 WPF 版升级

首个 WinUI 版本必须先退出旧程序，再运行完整安装器覆盖安装；旧版应用内更新器不能升级 WinUI 包。新版本首次启动时会把兼容的 `history.json`、`theme.json` 和图片导入 SQLite，并保留原始输入和迁移备份。由于尚未在一次性 Windows 账户完成 WPF→WinUI 安装器迁移验收，本次不要尝试旧版应用内增量更新。

## 使用历史和收藏

- 新复制的文本、截图和支持的图片会保存在历史页；复制后点击记录即可再次复制。
- 搜索和类型筛选可缩小列表；收藏页只显示收藏记录。
- 收藏不受自动容量清理影响；手动删除单条记录或清空时会删除相应收藏。清空前会显示记录数、收藏数和图片数供确认。
- 记录在 `%LOCALAPPDATA%\ClipboardManager\history.db`；图片在 `images` 子目录；迁移输入/备份和日志也留在该数据目录。

## 更新

更新中心将自动检查、手动检查、下载与安装分开：

- 开启自动检查后，应用启动 20 秒进行首次检查，之后每 60 分钟检查一次；关闭此设置时不发起自动网络请求。
- 自动检查只显示新版本提示，不会自动下载或安装。
- 点击“检查更新”可手动查询；只有明确点击“下载并更新”才会下载。下载和校验阶段可取消；开始交接后不能取消。
- 校验通过后，独立更新 worker 关闭应用、同卷备份并替换受清单管理的程序文件，然后启动新版。若替换或健康启动失败，会恢复旧版；历史、图片、数据库、设置和迁移备份不在更新清单目标内。
- 安装目录不可写时，安装版请运行完整安装器覆盖；便携版请退出程序后手动解压完整新包，不要把 ZIP 内容合并到正在运行的目录。

## 隐私和安全

应用不上传剪贴板文本或图片；更新请求只访问固定 GitHub Release 元数据和程序附件。诊断日志使用脱敏字段，不序列化异常消息或剪贴板内容。剪贴板可能包含密码或验证码，如需避免记录，请暂停监听。

发行版未做代码签名，Windows 可能提示未知发布者。HTTPS 和 SHA-256 可发现传输损坏或附件不匹配，但不能抵御仓库/Release 权限被攻破后清单与文件同时遭替换。请仅使用你信任的仓库发行版，并核对随包 SHA-256：

```powershell
Get-FileHash .\ClipboardManager-<版本>-win-x64.zip -Algorithm SHA256
Get-FileHash .\ClipboardManager-<版本>-win-x64-setup.exe -Algorithm SHA256
```
