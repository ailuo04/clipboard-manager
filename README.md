# 剪贴板

Windows 11 中文桌面剪贴板管理器。原工作目录为空，因此采用 .NET 8 WPF 和 Win32 API 从零创建；没有第三方 NuGet 依赖，不使用浏览器剪贴板轮询。

## 运行

本机已经构建好，可直接双击：

```text
bin\Release\net8.0-windows\ClipboardManager.exe
```

也可以在项目目录的 PowerShell 7 中运行：

```powershell
.\Start.ps1
```

程序只在窗口运行、监听未暂停时采集新发生的复制操作。最小化后继续监听；关闭窗口会释放监听器并退出。不在启动或恢复监听时补抓当前剪贴板，因此暂停期间复制的内容不会被补记。

## 构建

有 .NET 8 或更新 SDK 时使用标准命令：

```powershell
dotnet build .\ClipboardManager.csproj --configuration Release
dotnet run --project .\ClipboardManager.csproj
```

当前机器只有运行时，没有 SDK。项目提供不下载、不安装依赖的替代构建：

```powershell
.\build.ps1
```

脚本优先使用已有 SDK；没有 SDK 时，使用 PowerShell 7 已有的 Roslyn 编译器和本机 .NET 8 Windows Desktop Runtime。XAML 作为嵌入资源加载，两条构建路径使用同一套应用代码和界面。备用构建还利用 Windows 自带的 .NET Framework 编译器生成无控制台启动器；主程序仍运行在 .NET 8 WPF 上。此路径不是自包含发行包，换机器需要 .NET 8 Desktop Runtime。

## 功能与规则

- 文本列表与等比例图片卡片按采集时间倒序排列，显示类型、时间、字符数或图片尺寸。
- 点击记录主体复制完整内容；右侧按钮分别为固定、详情、删除。文本详情可以选择、滚动查看完整文本，图片详情支持适应窗口及缩放。
- 搜索匹配完整文本，而不是仅匹配预览；图片在有搜索词时不显示。支持全部、文本、图片筛选。
- 相同文本按完整 UTF-8 内容哈希去重；相同图片按标准化像素和尺寸哈希去重，不依赖文件名、PNG 编码元数据或来源。重复复制更新原记录时间，并保留固定状态。
- 监听通知防抖为 100 ms，短时间内的密集变化可能合并为最后一次内容。应用回写携带进程专用标记，不会触发历史反馈循环。
- 默认最多 500 条记录、512 MB 内容数据。容量计算包括文本 UTF-8 字节与 PNG 文件大小，不包含 JSON 格式开销与日志。自动清理先移除最早的未固定记录；固定记录不自动清理，所以固定内容本身可超过限制，界面会提示。
- 清空包含固定记录，操作前需确认；单条删除和清空均删除对应图片。文件被占用或无权限删除时，显示错误提示并持久化待删除队列，在后续操作或重启时重试。
- 应用单实例运行，不提供开机启动、系统托盘或全局唤起快捷键。

## 图片来源

读取的是系统剪贴板中的实际数据：注册格式 `PNG`、`image/png`、`JFIF`、`JPEG`、`image/jpeg`、`BMP`、`image/bmp`，以及标准 `CF_DIBV5`、`CF_DIB`、`CF_BITMAP`。注册格式解码失败时会继续尝试标准位图数据。DIB 会补齐 BMP 文件头，并处理调色板、位掩码、正负高度及 DIBV5 alpha。

因此截图所使用的 DIB/DIBV5/Bitmap 数据不需要文件路径。文件资源管理器复制的图片则通过 `CF_HDROP` 获取来源路径后立即读取像素、重新编码并保存，历史记录不依赖源文件继续存在。一次复制多个图片文件时，当前仅采集其中第一个支持的图片文件。

单次剪贴板数据读取上限为 128 MB、Unicode 文本数据上限为 8 MB、解码图片上限为 4000 万像素。超过上限会提示错误，防止异常数据导致过量内存分配。GIF/TIFF 只保留首帧；WebP 文件是否可读取决于系统可用的 WIC 解码器，不属于保证范围。

## 数据与日志

```text
%LOCALAPPDATA%\ClipboardManager\
  history.json       文本、图片索引、设置、待删除队列
  images\*.png       持久图片像素
  app.log            诊断日志
  app.log.old        上一次轮转日志
```

历史元数据先写入同目录临时文件，再原子替换正式文件；成功后才发布内存状态和删除旧图片。失败时保留旧状态，清理本次新增图片。损坏或不可读的历史文件不会直接当作空记录覆盖，应用会显示错误与重试入口。只会在成功加载有效索引后清理无引用图片。

剪贴板操作在独立 STA 线程执行；系统剪贴板占用时有限次数退避重试。图片解码、编码、文件读写与缩略图生成不在界面线程上运行。列表启用虚拟化，可见图片异步加载，离开视口后释放缩略图。

日志包含操作上下文、格式名、错误码和异常堆栈，不主动写入完整剪贴板文本。日志约 2 MB 后轮转一次。设置中可打开数据目录或日志。

所有历史均保存在本机，不进行网络上传；文本和图片没有额外加密。复制敏感信息前可暂停监听，并按需删除历史。此工具不等同于安全密码管理器。

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `Services/ClipboardMonitor.cs` | 窗口消息监听、幂等注册、注销 |
| `Services/ClipboardReader.cs`、`StaTaskRunner.cs` | 原生剪贴板读取与回写、独立 STA、占用重试、自写入标记 |
| `Services/ImageProcessor.cs`、`ImageLoader.cs` | 图像解码、DIB 处理、像素哈希、PNG 编码、缩略图 |
| `Services/HistoryService.cs` | 去重、排序、固定、容量策略、提交与删除管理 |
| `Services/HistoryStore.cs` | JSON 存取、原子替换、图片路径校验 |
| `ViewModels/` | 界面状态、搜索筛选、命令、错误反馈 |
| `Views/`、`Controls/`、三个窗口类 | 中文界面、异步图片、详情和设置 |
| `build.ps1`、`Start.ps1` | 本地构建与启动 |

## 验证

最终 44 项自动检查全部通过。检查使用隔离的测试数据目录，通过实际 Windows 剪贴板 API 注入文本及多种图像格式，并在结束后恢复原剪贴板。检查内容包括监听、去重、完整文本回写、PNG/JPEG/BMP/DIB/DIBV5、DIBV5 透明通道、损坏格式回退、图像回写、重启恢复、固定与容量、删除与清空、损坏索引保护、提交失败回滚、文件占用删除重试、搜索筛选、监听注册与释放、暂停隐私行为和窗口渲染。

另外渲染检查了 900×760 与 500×460 窗口、文本详情、图片详情、设置和错误状态。按本次任务要求，临时测试源码、测试数据和截图在验收后删除，保留应用源码及构建结果。

尚需用户在真实目标软件上完成以下端到端验收，不能用格式注入测试冒充这些操作已执行：

1. 启动应用后复制文本，确认出现；点主体后粘贴到记事本验证全文。
2. 在资源管理器复制 PNG/JPEG 图片，在浏览器使用“复制图像”，确认各自出现缩略图。
3. 按 `Win + Shift + S` 完成一次截图，确认历史自动出现图片；点该记录后粘贴到画图或聊天软件。
4. 关闭并重新启动程序，确认图片、全文和固定状态仍存在。
5. 删除图片或清空后，检查数据目录对应 PNG 是否消失。
